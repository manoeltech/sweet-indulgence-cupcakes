# Créditos das fotos dos cupcakes

As fotos da vitrine são do [Wikimedia Commons](https://commons.wikimedia.org), usadas conforme as licenças Creative Commons indicadas. As fotos representam o sabor de forma ilustrativa: não são produtos reais da loja.
